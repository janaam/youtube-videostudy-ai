Capítulo 01

O que é o Claude Code? (A analogia do gênio construtor)

🧩

Como programar parecia antes

Antigamente, você precisava aprender milhares de regras estranhas, pontos e vírgulas, e digitar cada linha manualmente. Se esquecesse uma letrinha, nada funcionava.

⚡

Como é com o Claude Code

É a programação baseada em prompts. Você conversa com a Inteligência Artificial como se fosse um colega humano: "Crie uma página de internet com tema escuro e um botão azul". O Claude Code planeja, digita o código e cria os arquivos no seu computador!

💡

O que é o "Terminal"?

O terminal (ou prompt de comando) é como uma linha telefônica direta com o cérebro do computador. Em vez de você clicar em ícones bonitos com o mouse, você escreve comandos em texto e o computador obedece imediatamente. O Claude Code vive dentro dessa linha direta!

Capítulo 02

As Fichas do Fliperama: Como Funcionam os Créditos?

🪙

Pense no Claude Code como uma máquina de fliperama. Para jogar, você precisa de fichas (chamadas de tokens de API ou uma assinatura Pro/Team da Anthropic).

Toda vez que você pede para o robô ler arquivos enormes ou criar códigos gigantescos, a máquina consome algumas fichas. Você não é cobrado de surpresa além do que colocar lá: quando as fichas acabam, o robô apenas para e espera você colocar mais.

Dica de Ouro #1

Comece com o plano mais simples

Não saia comprando créditos caros de início. Comece aos poucos para entender a ferramenta.

Dica de Ouro #2

O Modelo importa

Modelos mais potentes (como Claude Opus) gastam mais fichas. Modelos equilibrados (Sonnet) são perfeitos para o dia a dia.

Dica de Ouro #3

Use o comando /cost

Basta digitar /cost a qualquer momento para ver na tela exatamente quantas fichas você já gastou.

Fluxograma Obrigatório #2

Passo a Passo de Instalação no Computador

Escolha o seu sistema operacional e siga a trilha para ter o Claude funcionando.

🪟

Windows (PowerShell)

Recomendado pelo instrutor
  1. Abra a barra Iniciar do Windows e digite PowerShell.
  2. Cole o comando oficial de instalação:
irm https://storage.googleapis.com/claude-code-dist/install.ps1 | iex

Se o comando acima falhar, abra o terminal e use: npm install -g @anthropic-ai/claude-code

🍎 🐧

Mac e Linux (Terminal)

Para computadores Apple e Linux
  1. Abra a pesquisa Spotlight (Command + Barra de espaço) e abra o Terminal.
  2. Cole o comando de instalação:
curl -fsSL https://storage.googleapis.com/claude-code-dist/install.sh | bash

Certifique-se de que você já tem o Node.js instalado no seu sistema.

E depois que instalar? O Ritual dos 3 Passos:

Passo 1
Digite claude

No terminal, escreva claude e aperte Enter. A interface se abrirá.

➜
Passo 2
Conecte sua Conta

O navegador vai se abrir sozinho para você fazer login na sua conta Anthropic.

➜
Passo 3
Diga "Eu Confio"

Ele pergunta se você confia na pasta atual (Trust folder). Diga Yes!

Capítulo 03

Os Comandos Especiais (Começam com barra "/")

Quando você estiver conversando com o Claude no terminal, use estes comandos como atalhos de poder.

/clear
Limpar o Quadro Negro
Apaga a conversa antiga para começar um assunto novo do zero, sem confundir o robô.
/compact
Resumo Esperto
Se a conversa ficou muito longa, ele resume tudo o que aprenderam até agora. Economiza fichas e memória!
/cost
Ver a Conta
Mostra exatamente quantos tokens e dinheiro a sessão atual já consumiu.
/agents
Contratar Ajudantes
Cria robôs auxiliares para dividirem o trabalho (um cuida da carcaça do site, outro do motor).
/help
Manual de Instruções
Lista na tela todas as opções e truques que o Claude Code sabe fazer.
Fluxograma Obrigatório #4

A Nave Mãe: Tarefas em Segundo Plano, MCP e Habilidades

Como o Claude se conecta a outros programas para virar um assistente completo.

⚡

Claude Code

O Cérebro Central

Background Tasks

Tarefas em Segundo Plano

O Claude pode colocar tarefas demoradas (como instalar dezenas de programas) para rodar sozinhos enquanto você continua conversando com ele.

Subagentes (/agents)

Trabalho em Equipe

Em vez de um robô fazer tudo, ele cria especialistas: um cuida do design visual, outro cuida do banco de dados.

Servidores MCP

Cabos Conectores

O protocolo MCP é como um cabo USB que liga o Claude ao seu Google Drive, Notion, Gmail ou qualquer serviço externo!

Skills (Habilidades)

Receitas Reutilizáveis

Você pode ensinar um procedimento uma vez e salvar como uma "Skill". Na próxima vez, basta dizer: "Execute a Skill X".

Visão Completa

📋 Resumo Geral de Toda a Transcrição do Vídeo

Tudo o que foi falado no vídeo de 35 minutos sintetizado em tópicos claros e objetivos.

01

Conceito e Filosofia do Claude Code

O Claude Code é a resposta oficial da Anthropic para a nova era de ferramentas de desenvolvimento por inteligência artificial, operando diretamente na linha de comando (terminal). Ele foi projetado para permitir que qualquer pessoa crie, teste e modifique projetos de software apenas conversando através de instruções textuais (prompts), sem precisar escrever linhas manuais de código.

02

Requisitos e Custos de Utilização

A ferramenta exige uma conta paga na Anthropic (planos Pro, Max, Teams ou Enterprise) ou uma chave de API com créditos comprados no Console da Anthropic. O autor do vídeo recomenda enfaticamente iniciar pelo plano mais básico e acompanhar o consumo com o comando /cost para evitar gastos desnecessários antes de dominar a ferramenta.

03

Instalação e Configuração nos Sistemas Operacionais

No Windows, a instalação é recomendada pelo PowerShell com comando de uma linha; no Mac e Linux, utiliza-se o curl com bash. Caso o usuário prefira uma interface visual mais amigável, o autor mostra a alternativa do aplicativo Claude Desktop (com alternador entre modo Chat e modo Code).

04

Segurança e Boas Práticas (Git e Trust Folder)

Por segurança, na primeira execução o Claude exige confirmação explícita de confiança no diretório onde está rodando (Trust Folder). Além disso, o vídeo destaca a importância fundamental do Git para criar pontos de restauração (checkpoints) do projeto, garantindo que qualquer alteração inadequada feita pela IA possa ser desfeita instantaneamente.

05

Ciclo de Desenvolvimento e Engenharia de Prompt

O desenvolvedor demonstra na prática como pedir a criação de um projeto, solicitar a inclusão de novas páginas e regras visuais, e como o Claude Code pede permissão antes de modificar arquivos ou rodar comandos no terminal. A melhor estratégia é ser específico no que deseja e fornecer pequenos passos incrementais.

06

Otimização de Memória e Custos

Conforme a conversa avança, o consumo de tokens aumenta. O comando /compact resume o histórico mantendo as decisões importantes e limpando ruídos, enquanto o /clear inicia uma nova tarefa limpa sem carregar o contexto antigo.

07

Recursos Avançados e Ecossistema Extensível

O vídeo conclui apresentando os recursos mais poderosos da ferramenta: tarefas executadas em segundo plano (Background Tasks), divisão de tarefas entre múltiplos subagentes (/agents), integração com serviços externos através de servidores MCP (conectando a dados do Notion, Google Drive e bancos de dados) e a criação de Skills personalizadas para automatizar rotinas repetitivas.
